# Fuentes de datos

Las bases de datos propuestas provienen del Observatorio Nacional de Seguridad Vial del Ministerio de Transportes y Comunicaciones.

Enlace principal:  
https://www.onsv.gob.pe/datosabiertos

Bases consideradas:

1. Siniestros de tránsito fatales 2021-2025.
2. Personas involucradas en siniestros de tránsito fatales 2021-2025.
3. Vehículos involucrados en siniestros de tránsito fatales 2021-2025.

Los archivos originales no se almacenan directamente en este repositorio para mantenerlo ligero.
